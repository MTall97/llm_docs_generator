# Les bonnes pratiques pour choisir un mot de passe

## Qu'est-ce que un mot de passe?

Un mot de passe est une phrase qui contient des chiffres et/ou caractères spéciaux, généralement utilisés pour sécuriser votre compte.

- chiffres
- caractères spéciaux

## Les bonnes pratiques pour choisir un mot de passe

Un mot de passe est une clé unique qui vous permet de vous authentifier en ligne. Il est essentiel de choisir un mot de passe approprié pour protéger vos informations personnelles et faciliter la vérification de votre identité.

- Avantages
- Un mot de passe protège vos informations personnelles

En plus de protéger vos informations, un mot de passe est aussi utile car il permet de vous authentifier facilement en ligne. Vous pouvez facilement vérifier votre identité et vous authentifier avec un mot de passe.
